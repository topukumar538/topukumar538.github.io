OpsIQ — AI assistant for chat, document Q&A & incident analysis

Python · FastAPI · LangGraph · LangChain · FAISS · PostgreSQL · Async SQLAlchemy

A session-based AI assistant supporting general chat, document question answering with FAISS retrieval, and log-triggered incident analysis, with responses streamed through Server-Sent Events.

  • Incident-analysis workflow: Generates structured postmortems through a 5-node LangGraph pipeline. Log analysis and timeline extraction run in parallel before root-cause synthesis and remediation suggestions, with report-grounded chat for follow-up questions.
  • LLM configuration: Uses three LLM instances configured at temperatures of 0.7 for chat, 0.3 for document Q&A, and 0.1 for postmortem generation.
  • Session recovery: Persists conversation summaries and recent messages in PostgreSQL, alongside disk-backed FAISS indexes organized by user and session, to support restoring context when saved data remains available.
  • Request safeguards: Includes upload size checks, duplicate detection, session locking, pipeline timeouts, and request rate limits.
  • Scenario tests: Includes 19 tests checking expected concepts in synthetic scenarios based on published GitLab, Cloudflare, and AWS postmortems.
  • Delivery: Uses Docker and GitHub Actions to run the test suite before deployment to Hugging Face Spaces.

ContentPlatform — personalized content feed

Python · FastAPI · PostgreSQL · SQLAlchemy 2.0 · APScheduler · Docker · Pytest · Locust

A personalized feed combining preference-based ranking, softmax exploration, and fresh content, with interaction decay and category limits to keep recommendations varied.

  • Ranking and exploration: Uses a slot-based ranker with softmax sampling at temperature 0.7 and 10% random injection. Caps a category at three of the top five slots to limit category concentration.
  • Preference updates: Weights views, likes, and saves at 1, 3, and 5, respectively, with a 30-day decay constant. Recomputes preferences in hourly batches using grouped aggregation and bulk updates.
  • Pagination: Uses seeded ranking and a shared seen-set to avoid duplicate selections across generated pages, with viewed-content filtering and handling for exhausted content.
  • Authentication: Supports cookie-based JWT authentication and email OTP verification. Checks user state on authenticated requests so account blocks take effect on the next request.
  • Testing and deployment: Includes 47 automated tests, with Docker Compose and a GitHub Actions workflow that runs tests before deployment.
  • Load testing: Tested with Locust from 10 to 500 concurrent users. Recorded approximately 99% request success and 800 ms p95 response time at 100 users in the test environment; testing at 500 users exposed database connection-pool exhaustion.
